# LocalFileCleanupAssistant / 本地文件清理助手

一个**只在本机运行**的 Windows 文件清理候选清单工具。它先扫描、只生成候选；未经二次确认，不会删除、移动或重命名任何文件。

- 不上传文件内容、文件名或路径
- 不联网、不收集遥测、不检查更新
- 使用 Windows 自带的 PowerShell 5.1 与 .NET Framework，不要求安装 PowerShell 7

## 功能

- **重复文件**：同大小分组 + 前缀哈希 + 完整 SHA-256，识别完全重复
- **大文件 / 临时文件 / 同名不同内容 / 可能的历史版本**
- **批量选择**：全选当前显示、选中同文件夹、同文件夹同类型、选中所有图片
- **反向剔除**：取消选中同文件夹、取消同文件夹同类型
- **预选重复副本**：每个重复组保留 1 份，其余勾选
- **最终操作清单**：按目录分组，逐项确认
- **三种处理方式**
  - 移到 Windows 回收站（默认，可还原）
  - 移到本地隔离目录（按批次保存，可整批恢复）
  - 永久删除（不进回收站，需输入“永久删除”确认）
- **安全擦除**：永久删除时可选“覆盖写入后删除”（大文件较慢，SSD 不能保证 100% 不可恢复）
- **快捷方式清理**：永久删除时可选删除目标精确匹配的 `.lnk`
- **痕迹清理**：Word/Excel/PowerPoint 最近使用、Windows 最近使用、Jump List、资源管理器 MRU；执行前先导出 `.reg` 备份
- **哈希缓存 + 部分哈希**：重复扫描更快，减少不必要的整文件读取
- **历史记录**：查看本地批次日志

## 环境要求

- Windows 10 / Windows 11
- Windows PowerShell 5.1（系统自带）
- .NET Framework 4.8（系统自带）

## 使用

### 方式一：单文件版

双击 `本地文件清理助手.exe`。程序会把内置脚本释放到：

- `%LOCALAPPDATA%\LocalFileCleanupAssistant`，或
- exe 同目录的 `LocalFileCleanupAssistantData`

### 方式二：脚本版 / 便携版

解压后双击 `启动.cmd`，或运行 `FileCleanupAssistant.exe`。请保留 `app` 文件夹完整。

## 安全模型

1. 启动后先确认扫描范围；
2. 扫描阶段只读取元数据，并对候选文件计算哈希；
3. 所有候选默认不勾选；
4. 执行前显示按目录分组的最终操作清单；
5. 默认进入回收站；可改为隔离目录；
6. 永久删除必须输入确认文字；
7. 任一文件失败会记录原因并暂停，不提升权限、不强制删除。

## 构建

在 Windows 上运行：

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

脚本会使用系统自带的 `csc.exe` 编译：

- `dist\单文件版\本地文件清理助手.exe`
- `dist\脚本版\本地文件清理助手-脚本版.zip`
- `dist\便携版\LocalFileCleanupAssistant-portable.zip`

并输出 SHA256。

## 已知限制

- exe 未签名，Windows Defender 的 ML 启发式可能误报（例如 `Program:Win32/Contebrew.A!ml`）。可以优先使用脚本版，或用 `build.ps1` 自行构建。
- “永久删除 / 安全擦除”不等于取证级擦除；SSD 磨损均衡、卷影副本、备份、OneDrive/网盘历史版本等仍可能保留数据。
- 空文件夹、相似图片/视频、损坏文件、扩展名不匹配等不在当前范围内。
- 删除文件释放的是**磁盘空间**，不是运行内存（RAM）。

## 隐私

本工具不会联网，也不会把文件内容、文件名、路径或扫描结果发送到任何地方。日志、隔离文件和扫描结果都保存在本机数据目录中。

发布或分享日志前，请先检查其中是否包含个人路径。
